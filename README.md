# JordanSegovia.com - Portfolio (HTML/CSS/JS)

## How to use
1) Put a short looped, muted video at `assets/video/hero.mp4` (5-12s, 2-8MB).
2) Replace `assets/img/portrait.jpg` with your headshot.
3) Update links/text in `index.html`.
4) Deploy on GitHub Pages, Netlify, Vercel, or Cloudflare Pages.

## Sections
- About (with awards and right-side photo)
- Projects (2 example cards)
- Certificates
- Contact

## Notes
- Black theme with glassmorphism, blurred spheres, and background video.
- No frameworks, minimal JS, fast to load.
